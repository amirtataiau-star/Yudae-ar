# Yudae — The Commons AR pilot

Open the [Yudae AR pilot](./yudae/) after GitHub Pages has been enabled.

This repository also includes the separate Behind the Curtain prototype. Both are preserved.

To publish: GitHub repository Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Phone: open the public HTTPS Yudae page directly in Chrome on Android, or Safari on iOS. The 3D models are hosted at relative HTTPS URLs in yudae/assets. Android placement requires a compatible ARCore device and Google Play Services for AR. Some iPhones may require a separately generated USDZ model for Quick Look. The ordinary 3D model and accessible 2D map remain alternatives.

The experimental camera overlay is not surface-anchored AR. This is a fictional vignette outside the nine primary Yudae scenarios.
